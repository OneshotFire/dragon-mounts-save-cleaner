    Using your cleaned copy

    1. Close the game and keep a backup outside your save folder.
    2. Choose the affected character’s JSON file and review the proposed removals.
    3. Download the cleaned copy. Replace the affected save with it, using the original filename.
    Where is my character save?

    On Windows, paste this path into File Explorer:

    %LOCALAPPDATA%\RSDragonwilds\Saved\SaveCharacters

    For a Wine wrapper, use its equivalent Windows user folder. Choose a character JSON, not a world .sav file. Keep downloaded backups outside SaveCharacters.
